# Azure Virtual Machine Deployment

## Objective

Deploy and manage a Windows Server virtual machine in Microsoft Azure.

## Environment

- Microsoft Azure
- Azure Virtual Machines
- Virtual Network
- Network Security Groups

## Deployment Process

### Resource Group

Created a dedicated resource group for lab resources.

### Virtual Network

Configured a virtual network and subnet for the virtual machine.

### Virtual Machine

Deployed:

- Windows Server
- Standard VM size
- Public IP address
- Azure managed disks

### Security

Configured:

- Network Security Groups
- Restricted RDP access
- Administrative account security

## Validation

Verified:

- Successful VM deployment
- Network connectivity
- Remote administration access

## Skills Demonstrated

- Azure Administration
- Azure Virtual Machines
- Resource Groups
- Networking
- Infrastructure Management
